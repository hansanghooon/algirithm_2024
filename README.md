# 🚀 알고리즘 스터디 레포지토리 (Algorithm Study Repository)

본 레포지토리는 꾸준한 알고리즘 학습과 문제 풀이 기록을 위해 생성되었습니다.
다양한 자료 구조와 알고리즘 기법을 공부하고, 실제 문제에 적용한 풀이를 아카이빙하는 것을 목표로 합니다.

---

## 📚 학습 주제 (Syllabus)

스터디에서 중점적으로 다루는 주요 알고리즘 및 자료 구조입니다.

* **자료 구조 (Data Structures)**
    * Queue, Stack, Deque
    * String
    * Set
* **주요 알고리즘 (Algorithms)**
    * Greedy (탐욕법)
    * Implementation (구현)
    * DFS/BFS
    * Sorting (정렬)
    * Brute-force search (완전 탐색) / Binary search (이진 탐색)
    * Divide and Conquer (분할 정복)
    * Dynamic Programming (DP, 동적 계획법)
    * Backtracking (백트래킹)
    * Tree (트리)
    * Graph (그래프)
    * Simulation (시뮬레이션)
    * Two pointers / Sliding window (투 포인터 / 슬라이딩 윈도우)

---

## 🗓️ 진행 및 업데이트 방식

* 스터디는 **주차별**로 진행되며, 각 주차에 해당하는 주제의 문제들을 해결합니다.
* 해결한 문제의 소스 코드와 풀이 노트를 **매주 본 레포지토리에 업데이트**합니다.
* 폴더는 각 주제 혹은 주차별로 정리되어 있어, 원하는 풀이를 쉽게 찾아볼 수 있습니다.
